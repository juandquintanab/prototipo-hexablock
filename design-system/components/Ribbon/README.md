# Ribbon

Cinta roja con colas plegadas para el dato que importa al lado del puntaje: "Tu mejor", "Nuevo récord", "Nivel 12".

- Fondo `ribbon-500`, colas `ribbon-700`, texto `white` a 20px en peso 800. No bajar de 18px: el contraste (3.96:1) solo alcanza para texto grande.
- Etiqueta a la izquierda y valor a la derecha. Envuélvela en `.hx-ribbon-wrap` para que las colas queden detrás.
