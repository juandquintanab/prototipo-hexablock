# LevelTile

Botón de nivel para Hexa Fit (15 niveles) y Hexa Sort (10 niveles): hexágono plano con el número grande en `tile` (Young Serif) y las estrellas ganadas debajo.

- **Completado**: color del juego (`game-fit` o `game-sort`) y sus estrellas.
- **Actual**: `sun-400` y respira suave (`hx-breathe`) para que el ojo lo encuentre.
- **Bloqueado**: `disabled` con candado `disabled-ink`. No se puede tocar.
- La ficha usa la figura elegida en el catálogo, así el selector de niveles también cambia de forma.
