# ProgressBar

Dos barras:

- **Progreso** (`.hx-progress`): pastilla `trim` que se llena de `piece-orange` con rayas blancas suaves, texto `body` centrado en `ink`. Metas de Hexa Sort y logros. El ancho se anima en `dur-slow`.
- **Tiempo** (`.hx-timer`): barra fina `ink` que se vacía de derecha a izquierda. Solo en Hexa Fit, donde el tiempo cuenta para las estrellas. Va pegada arriba de la pantalla.
