# Settings

Controles de la pantalla de ajustes, dentro de un letrero "Ajustes":

- **Interruptor** (`.hx-toggle`, `role="switch"`): apagado `disabled`, encendido `grass-700`. La perilla salta con `ease-bounce`. Para sonido y música.
- **Pastillas** (`.hx-pills`): elección exclusiva corta, como el idioma ES / EN.
- **Fila** (`.hx-setting`): ícono `wood-700`, nombre y control a la derecha, separada por línea punteada `trim`.

La fila "Figuras" abre el catálogo de tablero y ficha.
