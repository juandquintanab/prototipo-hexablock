# Icons

Íconos de trazo redondeado, 24px, trazo de 2.6, dibujados con `HexaBlock.icon(nombre, tamaño)`. Heredan el color del texto (`currentColor`).

- Sobre botones amarillos van en `sun-ink`; sobre panel, en `wood-700`.
- Solo dentro de botones de ícono, filas de ajustes y contadores. Nunca sueltos como decoración.
- Nombres: back, play, pause, sound, mute, music, globe, undo, redo, gear, trophy, lock, home, retry, close, shapes, user, map, next.
