# IconButton

Botón cuadrado redondeado con un ícono: atrás, sonido, deshacer, rehacer. La pausa es la única redonda, para encontrarla sin buscar.

- Amarillo (`.hx-ibtn`) para controles del juego; versión panel (`.hx-ibtn--panel`) para ajustes y ranking sobre el mapa.
- Tamaño 56px (44px en `.hx-ibtn--sm` para deshacer y rehacer en el HUD).
- Siempre con `aria-label` en español o inglés según el idioma.
- Posición fija: atrás arriba a la izquierda, pausa y sonido arriba a la derecha.
